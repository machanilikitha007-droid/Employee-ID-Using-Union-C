# Employee ID Using Union in C

## Project Description

A simple C program that demonstrates the use of a union to store an employee ID in different formats. The user can choose between a numeric employee ID and a text-based employee ID.

## Features

- Store numeric employee ID
- Store text employee ID
- Display the selected employee ID
- Demonstrate union memory sharing
- Simple menu-driven program

## Technologies Used

- C
- Union
- Conditional Statements
- Standard Input/Output

## How to Run

1. Create a file named `employee_id_union.c`.
2. Compile the program using a C compiler.
3. Run the compiled program.

Example using GCC:

```bash
gcc employee_id_union.c -o employee_id_union
./employee_id_union
